## Estrutura
- `index.html` — o site inteiro (HTML, CSS e JS)
- `img/` — logo e fotos
- `COMO-CONFIGURAR.md` — como ligar a Área da loja (cadastro de Novidades) ao Supabase

## Área da loja
Acesse `/#admin` para cadastrar, editar, marcar como esgotada e remover peças das Novidades.
Sem o Supabase configurado, funciona em modo demonstração (salva só no navegador).
